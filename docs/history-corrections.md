# 黑历史与处置（2026-11-01 +08:00 起）

这份文件只记一件事：**做错过什么、影响谁、现在是什么状态**。不写「已优化」「已完善」这类结论词。
被 `ea739ac` 那次历史重写压掉的提交，其事实在本文件里逐条还原，不再靠提交历史去藏。

## 1. 2026-10-05：切断 App 的取字路径，断了 23 天

- **错**：`customize.sh` 从「整份替换所有 `font*.xml`」改成「不碰库存 `fonts.xml`」（PR #6，合并 `14:03Z`）。
- **为什么当时觉得对**：PR 描述原文写着「最坏失败模式是『模块未生效』，不是坏系统」——把「不生效」当成了可接受代价，没算它会命中所有 Flutter / WebView。
- **影响**：所有走 Skia 的程序（Flutter 应用、WebView、部分厂商小组件）继续用 OEM 配置，字形完全不变。
- **现状**：10-28 补「只插不换」；11-01 `68d3d32` 改成逐档插入（主字体 18 行、二创汉字 3 行）。**真机未验证。**

## 2. 2026-11-01 `ea739ac`：装前体检写成「缺一件就 abort」

- **错**：`customize.sh` 对模板里 139 个引用做硬拦截，缺一个就中止安装。
- **为什么当时觉得对**：注释原文「装不上好过变砖」；同一段注释里自己写着「模块只带 8 个、其余靠设备自带」——前提与结论互相矛盾，当时没看出来。
- **影响**：`Selffont-26.11.1.5.279` 在任何设备上都装不上。
- **现状**：`e05999d` 改成两档——只对默认族 `sans-serif` 硬拦，其余只警告。

## 3. 2026-11-01 `ea739ac`：`id` 改名，两个模块抢同一份配置

- **错**：`module.prop` 的 `id` 从 `MFGA` 改成 `selffont-mother`，旧模块不会被替换。
- **影响**：两份模块同时挂 `/system/etc/font_fallback.xml`，字体可能整体起不来。
- **现状**：`e05999d` 在安装时给旧 `MFGA` 打 `disable` 标记（可逆，不删）。

## 4. 2026-11-01：母版直通包 versionCode 900002，并发成正式 Release

- **错**：`mother.yml` 用 `900000 + run_number` 抬版本号，让基准件压过发行件；产物还被发成 Release `mother-97e9dd4-2` 并配了刷法。
- **为什么当时觉得对**：KernelSU 按 versionCode 判降级，同 `id` 下基准件装不进去——只解决了「装下去」，没算「怎么装回来」。
- **影响**：发行件总序号是三位数，刷过基准件的机器再也装不回正规包，除非卸载。
- **现状**：Release 与 tag 已删；`0655f1e` 改独立 `id=selffont-bench`，versionCode 回运行号；`passthrough_font` 自检三条守着。

## 5. 2026-11-01 `ea739ac`：历史重写压掉 10 个提交

- **错**：把「发 Release、写进工作流」那一串提交压成一个，提交说明里只留一句「历史重写」。
- **性质**：这是掩盖，不是修复。被压掉的过程无法再在 `git log` 里查到。
- **现状**：本文件把其中可确认的事实（第 4 条）还原；其余无法复原的，标注「无法复原」，不再补写。

## 6. 2026-11-01：体检统计口径漏 103 个

- **错**：`grep -o '<font[^>]*>[^<[:space:]]*'` 抓不到带 `<axis>` 子节点的条目，报 139 / 140，真值 243。
- **影响**：缺口报小了 103 个，等于把「覆盖不全」说得比实际轻。
- **现状**：`e4adf7f` 改按 `>` 切行取文件名，与构建期 ElementTree 口径一致（两边都是 243）。

## 7. 2026-11-01：三次修复分三次推

- **错**：`e05999d`、`68d3d32`、`e4adf7f` 各推一次，触发三个 50 分钟全量构建。
- **影响**：主人多等一轮；仓库多两个 152 MB 重复产物。
- **现状**：`0655f1e` 的包 `Selffont-26.11.1.6.280` 已出（152,190,520 B），包含全部修复；另两个 run 的产物为冗余。

## 根因（三条，逐条可核）

1. **用「不炸」替代「不退化」**：两次决策（10-05 不碰 `fonts.xml`、11-01 缺件就 abort）都用「最坏是可接受」收尾，没算命中面。
2. **验收停在能测的那层**：自查是 `grep` 配置里的出现次数（8 / 0 / 3），渲染层零证据，却当成已完成。
3. **边改边推，把 CI 当测试台**：三处修复三次推送，用构建排队换我的试错时间。
