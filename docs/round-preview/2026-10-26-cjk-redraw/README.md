# 2026-10-26 覆盖补齐与二创四字

## 一、覆盖去哪了（实测）

主字体是文渊圆体 `WenYuanRoundedSCVF.ttf` v1.100（48,779,368 B），不是 Maruko。

| 对象 | 码位总数 | 主人贴的那批 |
|---|---|---|
| 文渊主字体 | 33,032 | **0 / 315** |
| 构建 `prune_blank_mappings` 后 | 33,032 → 33,032 | 剪掉 **0** |

文渊基底停在 Unicode 14 之前：连 U+11F00（Kawi）、U+1E030（西里尔修饰）都没有。
主人贴的 315 个码位里 298 个是 Unicode 15–18 新分配，17 个到 Unicode 18.0 仍未分配。

## 二之二、20 个未分配码位自绘占位

「全字符覆盖」不能缺角，所以这 20 个按所在区块的风格自绘占位（`tools/reserved_glyphs.py`）：

| U+1FAC7/C9/CA/CB | 人物与生物 emoji | 头 + 圆肩 / 方肩 / 三角身 / 双人 |
| U+1FADE | 腌菜、泼溅 | 带盖的罐 |

## 三、二创四字（母版是 Maruko，坐标是从骨架里量出来的）

前几轮我在文渊上做二创，被主人否了：**二创的母版是 Maruko**，文渊只是最终生产
路径里的宿主（文渊笔宽 82，Maruko 66/67，两者不是一套比例）。

现在的做法不再手比坐标——`tools/maruko_skeleton.py` 直接从 Maruko 字形里量：

1. 栅格化（SS=2）→ 距离变换（顺手量出半笔宽 32.0/30.9/30.2/32.6）；
2. 中轴骨架 → 8 邻接图 → 「剥面条」反复取最长路径，一条一条把笔画取出来；
3. 末端**回卷钩**按累计转角 65° 切掉（`乙`/`九` 的钩短而急、`了`/`子` 的尾
   长而缓，只有累计转角对两种都成立）；
4. 切口沿笔画主轴拉直，再把断口补回原墨迹极值，字不会缩水；
5. 轮廓 = 中线按 2×33 描边、**圆端头 + 圆转角**后并集。

所以端头就是 Maruko 那种半径 33 的正半圆，拐角是圆弧，整条轮廓上没有一个折角。

| 字 | IoU（对 Maruko，含被切掉的钩） |
|---|---|
| 乙 | 0.849 |
| 了 | 0.795 |
| 子 | 0.836 |
| 九 | 0.874 |

上一版手估坐标的 IoU 是 0.421 / 0.374 / 0.230 / 0.218——同样的量法，差了一倍多。
