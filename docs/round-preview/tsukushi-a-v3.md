V3 以单一静态筑紫 A D/400 为研究基准，只处理 7 个唯一字形的 8 处钩尾；其余轮廓不变。“包”有两处，“乙”未检出钩。没有通用凸角处理、短弯合并、笔画宽度归一、生产构建或真机验证。

V3 使用分别匹配两端轮廓切线的两段二次曲线构成端头。自交检查通过只说明该项几何预检未发现单轮廓自交，**不能证明形状好看**。V3 的端头做法已在 V4 中重新设计为对称双弧候选；V4 仍待视觉判断。
