## 复算命令（沙箱，.venv）

```sh
# 三张图（roster-20 / insert-before-after / choose-0-100）：
# 打印每张的字节与 sha256，并打印 markdown 内联行（脚本自己给内联，不靠记得贴）。
.venv/bin/python tools/draw_round30_proof.py \
  /tmp/mother/Maruko.ttf /tmp/stray.ttf \
  /tmp/fakeroot/system/etc/fonts.xml /tmp/pkg430/system/etc/fonts.xml \
  /tmp/pkg430/system/fonts/Selffont-MarukoGothicCJKsc.ttf

# 投放层（配置层证据，stdout 存 2026-11-26-apply.txt）：
# 注意 MODDIR 由 skia.sh 自身路径推导（module/skia.sh:24），必须跑包内副本，
# 传位置参数会被静默忽略且报「没有插入行」——那句报错不指真因。
SELFFONT_SYSTEM_ROOT=/tmp/fakeroot bash /tmp/pkg430/skia.sh apply

# 选择层（配置层证据，stdout 存 2026-11-26-choose.txt，前后各一次）：
.venv/bin/python tools/skia_paths.py /tmp/fakeroot/system/etc/fonts.xml \
  /tmp/pkg430/system/fonts/Selffont-MarukoGothicCJKsc.ttf
.venv/bin/python tools/skia_paths.py /tmp/pkg430/system/etc/fonts.xml \
  /tmp/pkg430/system/fonts/Selffont-MarukoGothicCJKsc.ttf
```

`/tmp/stray.ttf` 由 `tools/drop_stray_ring.py /tmp/mother/Maruko.ttf -o /tmp/stray.ttf` 产生
（与 CI 同参数）；`/tmp/pkg430` 是本地同内容包解压（`build.py --passthrough-mother /tmp/stray.ttf
--base /tmp/base_local.zip --date 26.11.26 --day 13 --build 430`，版本号抄 CI run 45736506390
