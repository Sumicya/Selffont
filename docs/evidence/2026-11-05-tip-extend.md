# 2026-11-05 · 定位之后再补一层：收笔尖补齐（600 字 dH |>5| 14 → 9）

上一轮 `9a69d86` 把**位置**修好了（600 字墨心差中位 −0.5/+0.5 → 0/0，|差|>5 的 102/97 → 0/0）。
修完还剩 5 个 dW、14 个 dH 超过 5 单位，当时的结论是「形状差，仿射挪不出来，本轮不碰」。
这一轮把这一块也修了：**不是拉长整字，是补尖**。

## 一、先找反例：600 字不够，换 1500 字随机全库

600 字是 GB2312 一级每 6 个取一个，全落在常用字里。补尖之前先用**全库随机 1500 字**
（`random.seed(20261105)`，从 `design_cjk.bin` 的 33,931 个码位里抽）复核一遍，
按汉字/非汉字分开：

| 集 | 字数 | \|dcx\|>5 | \|dcy\|>5 | \|dW\|>5 | \|dH\|>5 |
| --- | --- | --- | --- | --- | --- |
| 汉字 | 1331 | 1（`𰣻` 24） | **0** | 10 | 34 |
| 非汉字 | 169 | 33 | 4 | 56 | 48 |

汉字的位置**确实**是收敛的（1331 字里只有 1 个扩展 B 区的生僻字差 24）。
非汉字那一栏不是这套判据的对象：拉丁与标点的左右位由侧距那条路决定，本来就不跟母版墨迹框走。

## 二、剩下那 19 个字是什么：尖没了

把 600 字里 |dW|>5 或 |dH|>5 的 19 个字逐个量「需要多少倍率才够」：

| 字 | dW | dH | 需要的倍率 | 母版有、本版没有的东西 |
| --- | --- | --- | --- | --- |
| 验 | 0 | −54 | y×1.062 | 佥上「人」的顶（母版 838，本版 788） |
| 笺 | 0 | −52 | y×1.056 | 竹头的尖、末撇的尖（母版 −122，本版 −96） |
| 基 | −40 | 0 | x×1.043 | 其下撇、捺的尖（母版 11 / 992，本版 31 / 972） |
| 式 | 0 | −40 | y×1.045 | 斜钩的尾尖（母版 −94，本版 −74） |
| 铲 | 0 | −38 | y×1.042 | 末撇的尖（母版 −122，本版 −103） |
| 席 | 0 | −36 | y×1.040 | 长撇的尖（母版 −104，本版 −86） |
| 妨 / 炎 / 硷 / 溃 / 俞 / 今 / 颅 / 伊 / 芭 / 瘪 / 待 / 鹿 / 鼠 | −18 ~ +12 | −16 ~ +6 | 1.006–1.020 | 同上的小量 |

共同点：**缺口都出在笔画的自由端**。母版的撇尖、捺脚是尖的（墨宽一路收到 0），
`design_cjk` 的骨架在这条中线还剩几十单位的地方就断了（距离变换到那里只剩一两个像素，
取骨架时被剪掉），拿半径 30 上下的**圆头**一补，尖端就短了一截。
`box_align` 对这种字故意不缩放（目标/现值比超过 4% 时那一轴不动、±2% 也夹不住），
所以只把中心摆正，长度差原样留着——这不是位置错，是形态缺。

## 三、改了什么：端头由半圆改成半椭圆（点数不变）

```
设计笔环 = 中线 + 逐点半宽 + 端头
端头原来是  p = 中心 + h·cosφ·n̂ + h·sinφ·t̂          （半圆，切向也只伸 h）
现在改成    p = 中心 + h·cosφ·n̂ + (h+δ)·sinφ·t̂      （半椭圆，切向伸到 h+δ）
```

- `δ` = 该端要补多长，由 `tools/tip_extend.py` 算：先按 400 档**真描一遍**得到实际墨迹框，
  与 `tools/master_box.bin` 的母版字面框比，短的那条边取最外、且外向切向压在这条边上的
  **自由端**，`δ = 缺口 ÷ 切向投影`，上限 60 单位。
- 斜端会顺带把另一条边顶出去（不设限时 `殴` 的 dW 从 0 涨到 18），所以再按母版框给
  **另一条轴**留 4 单位余量，超了按比例缩回来。
- **点数一个不动**：`ARC_STEPS` 不变，只是把半圆的点摆到半椭圆上。三档共用同一个 δ
  （`_ext` 记在笔画上），各自按自己的半宽算 reach——可变字体的点对点对应关系不动。
- 只补汉字；闭合环与零长度笔（字点）不动。

改动落在三处：`tools/design_cjk.py`（`_round_cap` 加 `reach`、`stroke_contours` 读 `_ext`）、
新增 `tools/tip_extend.py`、`tools/cjk_vf.py` 在描轮廓前调一次。

## 六、没修好的：三种，写清楚卡在哪

1. **`验` 的「人」顶差 50**：那个顶是两条笔画的**交汇点**，不是自由端——骨架把交汇点
   定低了 50。补尖只能往外伸自由端，伸不了交汇点。
2. **`笺` 的末撇差 24**：撇在母版里朝左下，本版的撇太竖（方向就不同），往斜下补会把
   已经对齐的左边顶出去，按第四节那个 4 单位余量只能补 2。
3. **`炎` `硷` 等 8 个差 6–8**：缺口落在笔画**中段**的极值上（比如长横的端点被圆头修掉
   一点点），不在端头，这轮的结构改不到。

这三类要动的是**骨架重取**（`tools/maruko_skeleton.py` 的端部与交汇点），
那是另一件工程：全库 33,931 字重出 `design_cjk.bin`，再逐条复核洞数与墨量。本轮不碰。

## 七、复算

```bash
# 母版（MarukoGothicCJKsc-Regular.ttf @ 97e9dd4，sha256 e3709389…7241b7）
python - <<'EOF'
x = [bytes([h, l]).decode('gb2312') for h in range(0xB0, 0xD8) for l in range(0xA1, 0xFF)]
open('/tmp/600字.txt', 'w', encoding='utf-8').write(''.join(x[::6][:600]))
EOF
python tools/tip_extend.py --chars "基验式席铲笺日口" --dry-run      # 逐字打印缺口与要补的端
python tools/tip_extend.py --chars "基验式席铲笺日口"               # 打印补后墨迹框

# 两个对照件（同一批 13 字）：补尖前的取上一笔提交 7f27ded 的 tools/，补尖后用本提交
git worktree add /tmp/before-tree 7f27ded
(cd /tmp/before-tree && python build.py --preview "基式席铲笺日口验炎妨硷久殴" --preview-out /tmp/before)
python build.py --preview "基式席铲笺日口验炎妨硷久殴" --preview-out /tmp/after
```
