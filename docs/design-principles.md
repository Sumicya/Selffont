# 设计原则

- 2026-10-22｜关键词：自动改形过度、笔画简化观感丑｜自动几何候选只用于定位；没有明确的目标字形与预期视觉、且未经同基准正常字号和局部放大核对前，不把算法候选直接当成设计结果或批量改字。
- 2026-10-22｜关键词：圆头不是平头、去钩继续做｜钩尾处理必须形成圆弧收头而不是平切；先把改动限制在已指定钩尾，局部放大核对端点衔接后再考虑扩大范围。
- 2026-10-22｜关键词：V3 丑、完整字形上下文｜端头局部几何干净不等于整体好看；收到明确负面观感时，将该版标作不接受，继续优化，并同时核对完整字形、同基准对照与端头细节。无自交或构建通过不得替代视觉验收。
- 2026-10-23｜关键词：粗细统一、授权字体参照、鸟/也分别对应、非临摹、圆头、电不加粗｜主人明确草图分别是“鸟”“也”，只能提炼各自整体造型思路，不描笔画、不混淆字符；全样本笔画粗细须在图上可见地统一，可借有许可的字体研究重量原则但不复制轮廓；钩尾用半圆收头，己/已末笔适度延长；电的中间田框收窄须围绕中线且恢复共同笔宽，不能加粗隔断，advance 与可见墨迹边界分别报告，不把几何量化当作审美通过。
- 2026-10-24｜关键词：当前图唯一明确、Maruko 自制 KR、区分笔宽处理与曲线精简｜审阅入口只突出一张标明日期和范围的当前主图；KR 不因上游无字重就直接止步于系统回退，先用 Maruko 自有 Jamo 做可逆 Hangul 原型；曲线控制点减少须如实称曲线精简，不冒充可见笔画简化；笔宽实验只按已确认范围实施，且不得擅自删减汉字语义笔画。
- 2026-10-24｜关键词：无钩别把点剪掉、笔画不许缩、要平滑、旧图清掉｜去钩只能去掉卷回去的那一小截、不许把笔画剪短（钩收到"看着是直的"就停）；不能把「点」「撇」这类独立短笔画当成钩；去钩后切口必须圆头收笔。以字根稿（214 部首）为审阅单位逐字看平滑度，不拿指标代替观感。主人本轮选的取向：钩只收到看着是直的就停（不切到钩根），因为切根会让竖弯钩短掉 2–3 倍笔宽。
- 2026-10-24｜关键词：上游的折也要修、磨平不缩笔画、直角不许圆｜放大后能看见的折角就是缺陷，"上游本来就有"不能当理由；修法只替换区段中间点、保留两端点与端点切向，所以笔长、交点都不动；磨完必须回头核对直角与锐角字（丁卜刀力弓乙乃匚山小）没有被圆化，且这一步要跑在曲线精简之前——它输出的是折线。
- 2026-10-24｜关键词：放大看端头、接头要相切、别拿指标当验收｜主人放大核图后看到的"边缘一波一波"和"端头不圆"必须当真：先分清是上游自带还是流水线引入，再动手；曲线精简的验收不能只看 IoU 与点数，还要看相邻段的切线是否连续（只连续不相切的二次曲线串在放大后必然呈多边形），以及端头半圆在 6000 px/em 下是否仍是圆。
- 2026-10-24｜关键词：先查根因再调参、曲线必须是曲线｜"边缘一波一波/端头不圆"这类问题要先查输出里到底有没有曲线段，再谈容差；曲线精简的验收必须报「线:弧」段数与单段最大转角，全是直线的输出无论 IoU 多高都是多边形字体。端头按真半圆做，单段圆弧转角不超过 90°（单段近似 180° 的径向误差 10.8%，两段 90° 降到 6.07%）；判自交必须按真实曲线取样，只查控制点会漏。
- 2026-10-24｜关键词：别把曲线展平再拟合、点数要跟原版比｜重描成折线再"精简"只会得到更差的折线：原版 `龍` 210 点含 58 段真曲线，我们"精简"后 276 点 0 段曲线。判断精简好不好，先跟原版的点数与曲线段数比，再看逐处放大的边缘；不能只看 IoU。
- 2026-10-24｜关键词：读原生、别重描｜上游描摹字体本身已经是干净曲线（`龍` 210 点含 58 段弧），任何"光栅化再描线"的中间步骤都会把它降级成折线；合并笔画要用保留曲线的布尔运算（pathops），不要重新采样。判断是否有必要做某一步，先量它改变了多少字形（214 部首里需要并集的只有 0 个）。
- 2026-10-25｜关键词：提炼设计思想、别在原设计上叠东西、横截面、标准半圆、等宽笔画｜主人两次要「提炼设计思想」，并明确「基本属于二创字了就不要在本来就不完美的原设计上加还没修平滑的东西」。据此定量读出 Maruko 的三条规则（86 字样本）：① **等宽笔画**——骨架半笔宽中位 31.1、四分位 30.5–32.0，字内离散度 IQR/r 中位 0.073；② **端头 = 半径等于半笔宽的标准半圆**——398 个自由端头的横向射线 d_min/r 中位 1.01、10 分位 1.00；③ **字形由骨架定形，笔画沿骨架等宽展开**。收笔必须按这三条**重新生成**，不能拿一个正圆去封原轮廓上斜切的刀口：切口法向若取骨架局部切向的垂线，在弯段上不等于横截面法向（`九` 差约 25°），弦被拉长到 1.11×2r → 端头宽 11% = 脓包；圆盘又有一半悬在笔画外（`也` 只剩 22.5% 是墨）= 缺口。正确判据是一条几何事实：**横截面 = 过骨架点、两端等距、弦长恰为 2×局部半笔宽的那条线**。用它重切后，六个字的弦/2r 全部 1.000、接缝角 0.3–17.5°、半圆盘内墨迹 99.8–100%。
- 2026-10-25｜关键词：别用光栅重描、保留原生曲线｜按骨架**栅格重画**（膨胀 + find_contours + approximate_polygon）虽然能把钩整条去掉，但会把细笔画抹平（`必` 的心、`包` 的内框、`電` 的雨丢失，IoU 0.79–0.93）。这与 2026-10-24「读原生、别重描」是同一条：轮廓上的操作必须保留原生曲线，重描只能当诊断图，不能当交付。
