# 设计取向（主人反馈 → 可判定的判据）

> **待主人审定**：首版由 2026-10-31 的会话从仓库里已有的主人反馈（提交说明、CHANGELOG、
> README 的「主人……」记录）提炼，阈值是我的提议，主人改哪条就按改后的执行。

每条都写成「对母版的哪一处、量哪个量、过线值多少、现在多少」。量不出来的不写进来；
写进来就必须能用一条命令复算，命令里的 `母版.ttf` 指 Maruko Gothic 的原始字件（不进仓库）。

## 1. 拉丁字对的间距以母版真排为准，宁可窄不许宽

- **判据**：`.venv/bin/python tools/kern_measure.py --master 母版.ttf --verify 本版.ttf`
  报出的 8,347 对里，`te` 与母版差 **≤5 单位**，全体 Δ白中位 **≤2 单位**，p90 **≤5 单位**。
- **现值**（2026-10-31 09:58 UTC+8，`work/fix14/static-400.ttf`）：`te` 164.5 / 164.5（差 **0**）；
  8,347 对中位 **1.3**、p90 **3.3**、≤5 单位 97.4%。
- **出处**：2026-10-31「te 之间太宽」。

## 2. 汉字按母版形状验收，不按「能看」，也不挑样字

- **判据**：`.venv/bin/python tools/freetype_iou.py 母版.ttf 本版.ttf --all`
  （两个字体 cmap 交集里 **U+4E00–U+9FFF 全部码位**，200 px、同基线、±1 px 对齐）：
  中位 **≥0.95**、p10 **≥0.90**、最低 **≥0.85**。
- **现值**（2026-10-31 10:02 UTC+8）：20,977 字，中位 **0.929**、p10 0.912、最低 **0.731**
  （`墫` `巽` `瑨`）；不对齐时中位 0.927、最低 0.724。**未达标**，差距在「边缘位移」不在「缺笔」。
- **看哪张图**：`docs/evidence/2026-10-31-hanzi-worst.png`（最差 8 字的上母版 / 下本版）。
- **出处**：2026-10-31「汉字呢」「不如母版」。

## 3. 字点按母版里那团圆墨的半径画，不按笔画半宽

- **判据**：`design_cjk.bin` 里 `.` `!` `?` `i` `：` 的字点半径与母版实测半径差 **≤2 单位**；
  量法是从母版轮廓里取包含该点的最小近圆墨团（边长 ≤200 单位），不用笔画半宽代替。
- **现值**：`.` 55.5（母版 55.5）、`i` 46.0、`?` 55.8、`!` 55.8、`：` 60.0。
- **出处**：2026-10-31「字点小一半」。

## 4. 三档粗细同一拓扑：点数逐一相同，不许按粗细重新求并集

- **判据**：`build.py --cjk-font` 结束时对 300/400/500 三档逐字断言点数相同（`tools/cjk_vf.py`），
  任一字不一致即抛错；笔画半宽落在 **0.02–0.09 em**。
- **现值**：33,931 码位全部通过，零拒绝。
- **出处**：2026-10-28「可变字体」；2026-10-31「不如母版」里对粗细的反复比对。

## 5. 行框跟设备空壳，墨迹不许出框

- **判据**：`hhea` 与 typo 的 ascender/descender/lineGap = 空壳的 930 / −250 / 0；
  `usWin` 盖住全库墨迹包络（不给负 `usWinDescent` 留洞）；墨迹包络不越 `usWin`。
- **现值**：`usWin` 1307 / 529，墨迹包络 −529…1307，相等（贴边、不越界）。
- **出处**：2026-10-05 真机（行框错位会跳行）；2026-10-31 复核。

## 6. 预览路径：改一笔，一分钟内看得见，不许等全量构建

- **判据**：`.venv/bin/python build.py --preview 鬱響鬢 --compare 母版.ttf` 在 **60 秒**内退出，
  产出 `work/preview/preview.ttf` 与 `work/preview/preview.png`（上排母版、下排本版、每格 IoU）。
- **现值**：3 字 **17 秒**（读 38 MB 数据 10 秒 + 编字 0.6 秒 + 出图 6 秒）；全量构建约 53 分钟。
- **出处**：2026-10-31 规范「视觉与字体仓必须有热重载／热切换的预览路径」；真机热切换见 README。

## 7. 不拿「换了字体」当理由：装到设备上的字，屏幕上必须能判

- **判据**：任何字形结论都要给「同一 FreeType、同一尺寸」的位图对照（上面第 2 条的图），
  只给矢量坐标或只给描述不算；真机截图属于**未验证**项，不冒充已验证。
- **现值**：README「未验证项的真机清单」列了三条没截图的能力。
- **出处**：2026-10-05 真机目视、2026-10-31「我不知道你tm到底想干啥」。
