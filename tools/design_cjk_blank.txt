# 空白字符码位表：母版里没有轮廓、但有 advance 的码位。
# 自研字库把它们补成零画笔的空字形（否则字件缺码位，系统逐字回退，空格宽度换家、
# 行宽与断行位置全变）。**advance 不从这里取**，宽度由构建期规则自算（见 cjk_vf.advance_of）。
# 格式：十六进制码位  # 字符
0020  # ' '
00A0  # '\xa0'
0339  # '̹'
0345  # 'ͅ'
037A  # 'ͺ'
0384  # '΄'
0457  # 'ї'
04E8  # 'Ө'
115F  # 'ᅟ'
2002  # '\u2002'
2003  # '\u2003'
3000  # '\u3000'
FFA0  # 'ﾠ'
